# Easy JavaScript Learning Repo

This repository is set up to help beginners learn JavaScript step by step.

## How to use

1. Open `/home/runner/work/js/js/run.html` in a browser.
2. Open **Developer Tools → Console**.
3. Read outputs from `apna.js` in order.

## Learning path

### 1. Start here: `apna.js`
Covers beginner topics in a clean order:
- variables and data
- operators
- strings and template literals
- objects
- conditionals
- loops
- arrays
- functions
- map/filter/reduce

### 2. Next level: `script.js`
Contains additional JavaScript concepts and examples.

## Tip
Pause after each section, edit values, and rerun to learn faster.
